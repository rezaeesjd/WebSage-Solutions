# Generation Workflow Structure

## Stage A — Classify
- Detect command
- Confirm generation-only scope vs publish scope

## Stage B — Clarify Gate
- Execute preflight requirements
- Return PASS / BLOCKED / PROVISIONAL

## Stage C — Facts Lock
- Build source-facts provenance matrix
- Mark every required field status

## Stage D — Strategy & Draft
- Produce conversion-aware assets using confirmed facts only

## Stage E — QA Enforcement
- Run 10-gate QA checklist
- Validate schema, cleanliness, link provenance, blockers

## Stage F — Status Decision
- Write honest generation outcome
- Output blockers and next required human actions

No stage skipping is allowed.
